# Soluciones detalladas

Todos los casos son académicos y ficticios, elaborados con fines educativos.

## Liquidez
Razón corriente = S/ 480,000.00 / S/ 300,000.00 = 1.60.
Prueba ácida = (S/ 480,000.00 - S/ 180,000.00) / S/ 300,000.00 = 1.00.

## Gestión
Cuentas por cobrar promedio = (S/ 180,000.00 + S/ 220,000.00) / 2 = S/ 200,000.00.
Rotación de cuentas por cobrar = S/ 1,200,000.00 / S/ 200,000.00 = 6.00 veces.
Periodo promedio de cobro = 360 / 6.00 = 60.00 días.
Inventario promedio = (S/ 140,000.00 + S/ 160,000.00) / 2 = S/ 150,000.00.
Rotación de inventarios = S/ 900,000.00 / S/ 150,000.00 = 6.00 veces.
Permanencia promedio = 360 / 6.00 = 60.00 días.

## Solvencia
Endeudamiento = S/ 900,000.00 / S/ 2,000,000.00 x 100 = 45.00 %.
Deuda-patrimonio = S/ 900,000.00 / S/ 1,100,000.00 = 0.82.

## Rentabilidad
Margen neto = S/ 135,000.00 / S/ 1,500,000.00 x 100 = 9.00 %.
ROA = S/ 135,000.00 / S/ 1,500,000.00 x 100 = 9.00 %.
ROE = S/ 135,000.00 / S/ 900,000.00 x 100 = 15.00 %.

## Caso integrador
Razón corriente = 1.80. Prueba ácida = 1.20. Endeudamiento = 47.50 %.
Deuda-patrimonio = 0.90. Margen neto = 8.46 %. ROA simple = 10.58 %.
ROE simple = 20.14 %.
