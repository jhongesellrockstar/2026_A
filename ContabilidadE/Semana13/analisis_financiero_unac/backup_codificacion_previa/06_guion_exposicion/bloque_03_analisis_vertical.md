# Bloque C: Analisis vertical

Duracion sugerida: 7 a 8 minutos

El analisis vertical estudia la composicion interna de un estado financiero en un solo periodo. Cada partida se expresa como porcentaje de una base comun.

Este metodo sirve para medir el peso de costos, gastos, activos, pasivos, patrimonio y margenes. En el Estado de Resultados, la base comun suelen ser las ventas netas. En el Estado de Situacion Financiera, la base comun suele ser el total de activos.

La formula es partida dividida entre base comun, multiplicada por 100.

Un ejemplo basico: si las ventas son S/ 100,000.00 y el costo de ventas es S/ 60,000.00, el costo representa 60.00 % de las ventas. Esto significa que de cada S/ 100.00 vendidos, S/ 60.00 se destinan al costo de ventas.

Un ejemplo aplicado a una empresa tecnologica: si las ventas son S/ 200,000.00 y los costos de servidores y licencias son S/ 70,000.00, esos costos representan 35.00 % de las ventas. Si ese porcentaje aumenta, se deben revisar proveedores cloud, licencias o arquitectura de servicios.

El procedimiento vertical consiste en elegir el estado financiero, definir la base del 100.00 %, dividir cada partida entre la base, comparar porcentajes e interpretar la estructura.

En Empresa ABC, el costo de ventas representa 60.00 % de las ventas en 2024 y 61.86 % en 2025. La utilidad bruta baja de 40.00 % a 38.14 %.

La interpretacion es que el costo gana peso dentro de las ventas y presiona el margen bruto. Aunque la utilidad neta aumente en soles, la lectura porcentual muestra que la rentabilidad relativa puede deteriorarse.

## Transicion

Con ambos metodos aplicados, corresponde compararlos y llevar los resultados a decisiones empresariales.
