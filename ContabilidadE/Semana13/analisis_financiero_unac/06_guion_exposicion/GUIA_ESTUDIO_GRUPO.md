# Guia de estudio del grupo

## 1. Resumen general

El analisis financiero interpreta estados financieros para evaluar desempeno, estructura, tendencias y decisiones empresariales. En esta exposicion se separa teoria, formulas, procedimientos, ejemplos aplicados y caso practico para facilitar el estudio.

El analisis horizontal compara una misma partida entre periodos. El analisis vertical expresa cada partida como porcentaje de una base comun. Ambos metodos se complementan y pueden automatizarse mediante herramientas de Ingenieria de Sistemas.

## 4. Formulas

Variacion absoluta:

`Valor actual - Valor base`

Variacion porcentual:

`Variacion absoluta / Valor base x 100`

Participacion porcentual:

`Partida / Base comun x 100`

## 5. Ejemplo basico de analisis horizontal

Enunciado: una empresa desea comparar sus ventas entre dos periodos para medir el crecimiento comercial.

Datos:

- Ventas 2024: S/ 100,000.00.
- Ventas 2025: S/ 120,000.00.

Formula:

- Variacion absoluta = Valor actual - Valor base.
- Variacion porcentual = Variacion absoluta / Valor base x 100.

Calculo:

- Variacion absoluta = S/ 20,000.00.
- Variacion porcentual = 20.00 %.

Interpretacion: las ventas aumentaron S/ 20,000.00, equivalentes al 20.00 % del periodo base.

## 6. Ejemplo cloud

Enunciado: una empresa de servicios digitales contrata infraestructura cloud para alojar su plataforma y observa un incremento del costo mensual.

Datos:

- Costo cloud 2024: S/ 8,000.00.
- Costo cloud 2025: S/ 12,000.00.

Calculo:

- Variacion absoluta = S/ 4,000.00.
- Variacion porcentual = 50.00 %.

Interpretacion: el incremento debe compararse con el crecimiento de usuarios o ingresos.

Decision: si los ingresos no crecen proporcionalmente, revisar arquitectura, proveedor cloud o plan contratado.

## 7. Ejemplo basico de analisis vertical

Enunciado: una empresa desea conocer que proporcion de sus ventas se destina al costo de ventas.

Datos:

- Ventas netas: S/ 100,000.00.
- Costo de ventas: S/ 60,000.00.

Formula:

- Participacion porcentual = Partida / Base comun x 100.

Calculo:

- Participacion = 60.00 %.

Interpretacion: de cada S/ 100.00 vendidos, S/ 60.00 se destinan al costo de ventas.

## 8. Ejemplo de estructura de costos tecnologicos

Enunciado: una empresa tecnologica desea evaluar que peso tienen sus costos de servidores y licencias dentro de sus ventas.

Datos:

- Ventas: S/ 200,000.00.
- Servidores y licencias: S/ 70,000.00.

Calculo:

- Participacion = 35.00 %.

Interpretacion: si este porcentaje aumenta, deben revisarse proveedores cloud, licencias y arquitectura de servicios.

## 9. Caso Empresa ABC

Ventas netas aumentan de S/ 180,000.00 a S/ 215,000.00, equivalente a 19.44 %.

Costo de ventas aumenta de S/ 108,000.00 a S/ 133,000.00, equivalente a 23.15 %.

La utilidad bruta crece menos que las ventas y el costo gana peso en el analisis vertical. Por ello, la empresa debe revisar eficiencia operativa.

## 10. Ejemplo comparativo

Enunciado: una empresa de servicios digitales observa que su gasto en servidores aumentó entre 2024 y 2025, y la gerencia quiere conocer tanto el cambio como el peso sobre ventas.

Analisis horizontal:

- Gasto 2024: S/ 8,000.00.
- Gasto 2025: S/ 12,000.00.
- Aumento: S/ 4,000.00.
- Variacion: 50.00 %.

Analisis vertical:

- Ventas 2025: S/ 40,000.00.
- Participacion del gasto: 30.00 %.

Decision: revisar sostenibilidad del costo, proveedor, arquitectura o plan contratado.

## 11. Preguntas probables de la docente

¿Por que no basta con decir que las ventas crecieron?

Porque se debe revisar si los costos y margenes evolucionan de manera favorable.

¿Que diferencia hay entre analisis horizontal y vertical?

El horizontal compara periodos; el vertical analiza estructura porcentual dentro de un periodo.

¿Como se aplica este tema en Ingenieria de Sistemas?

Mediante ERP, bases de datos, ETL, dashboards, reportes automatizados y alertas gerenciales.

¿Que herramienta puede automatizar estos calculos?

Excel, SQL, Python, Power BI, ERP o un sistema web de reportes.
