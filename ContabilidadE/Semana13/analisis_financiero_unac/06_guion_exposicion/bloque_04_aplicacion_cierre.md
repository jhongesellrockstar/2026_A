# Bloque D: Comparacion, decisiones y cierre

Duracion sugerida: 7 a 8 minutos

El analisis horizontal y el analisis vertical son complementarios. El horizontal tiene enfoque temporal y responde cuanto cambio una partida. El vertical tiene enfoque estructural y responde que peso tiene una partida dentro del estado financiero.

Un ejemplo integrado seria el gasto en servidores. Si sube de S/ 8,000.00 a S/ 12,000.00, el analisis horizontal muestra un aumento de S/ 4,000.00 y 50.00 %. Si ademas representa 30.00 % de las ventas, el analisis vertical muestra que tiene un peso importante en la estructura de costos.

Entre los errores frecuentes estan confundir ventas con rentabilidad, ignorar la base porcentual, leer cifras sin contexto y no complementar con ratios. Por eso el analisis financiero requiere interpretacion, no solo calculo.

Las decisiones empresariales derivadas pueden relacionarse con precios, costos, financiamiento, inversion, presupuesto y control de gestion. En Empresa ABC, el foco principal seria revisar el crecimiento del costo de ventas.

En Ingenieria de Sistemas, el analisis financiero puede implementarse como un flujo: ERP, base de datos, ETL, calculo financiero, dashboard y alerta gerencial. Herramientas como SQL, Excel, Power BI, Python o sistemas web permiten automatizar reportes y visualizar indicadores.

Como conclusiones: los estados financieros son la base del diagnostico; el analisis horizontal muestra tendencias; el analisis vertical muestra estructura; el caso ABC demuestra que vender mas no siempre implica mayor eficiencia; y la Ingenieria de Sistemas permite automatizar reportes, dashboards y alertas.
