# Simulador de Prestamos

Ejercicio de practica en PHP con formulario HTML, metodo POST, validaciones, funciones y tabla de amortizacion.

## Archivos

- `index.html`: formulario del simulador.
- `procesar.php`: procesa datos, valida, calcula cuota y muestra resultados.
- `styles.css`: estilos para el formulario y la tabla.

## Como probar

Copiar esta carpeta a un servidor con PHP y abrir `index.html`.
