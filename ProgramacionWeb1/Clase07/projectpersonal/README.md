# Project Personal - Aprendizaje de PHP y HTML

Este proyecto contiene ejemplos pequenos para practicar fundamentos de PHP junto con HTML. Sirve como carpeta personal de estudio para la Clase 07.

## Temas incluidos

- Sintaxis basica de PHP.
- Variables, constantes y operadores.
- Condicionales `if`, `else` y `switch`.
- Arrays simples y asociativos.
- Funciones.
- Formularios HTML enviados con `POST`.
- Uso de `number_format()` para mostrar numeros.

## Archivos

- `index.php`: pagina de inicio con resumen de conceptos.
- `examples/variables.php`: practica de variables, constantes y arrays.
- `examples/formulario.php`: formulario simple procesado en la misma pagina.

## Como probar

Colocar la carpeta en un servidor local con PHP y abrir:

```text
http://localhost/projectpersonal/
```
