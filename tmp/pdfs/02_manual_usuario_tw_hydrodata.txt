1.

Objetivo del manual

Orientar al usuario en la puesta en marcha y uso de TW HydroData, explicando el
acceso público, el acceso privado, los roles, los módulos de mantenimiento, los reportes y
las descargas CSV.

2.

Descripción del sistema

TW HydroData es una plataforma web de Tecprog World / TW INNOVA para gestión
y consulta de datos hidrométricos. Permite visualizar estaciones, campañas, aforos líquidos
y aforos sólidos, además de descargar información en CSV. El sistema cuenta con login
para editores y administradores.

3.

Requisitos previos
Windows 11.
XAMPP instalado.
Apache activo.
MySQL/MariaDB activo.
phpMyAdmin disponible.
Navegador web moderno.

4.

Instalación y puesta en marcha

1. Copiar el proyecto en C:\xampp\htdocs\hidroaforo_web.
2. Abrir XAMPP Control Panel.
3. Iniciar Apache y MySQL.
4. Ingresar a http://localhost/phpmyadmin/.
5. Importar database.sql.
6. Abrir http://localhost/hidroaforo_web/.
7. Verificar instalación en http://localhost/hidroaforo_web/verificar_instalacion.
php.

Aforos líquidos, Aforos sólidos, Descargas, Acerca y Contacto. No requiere usuario ni
contraseña.
