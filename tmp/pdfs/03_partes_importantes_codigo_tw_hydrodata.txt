1.

Introducción

Este documento explica los componentes técnicos más importantes de TW HydroData.
El sistema fue desarrollado sin framework pesado, usando PHP estructurado, MySQL/MariaDB,
HTML, CSS y JavaScript básico. La organización modular permite comprender fácilmente
la funcionalidad del sistema.

3.

Arquitectura usada

El sistema no utiliza MVC formal ni framework. Usa una arquitectura modular con
archivos de presentación, includes reutilizables, conexión centralizada, módulos CRUD,
consultas SQL y control de sesiones. Esta arquitectura es apropiada para Programación
Web I porque permite observar directamente el flujo entre formulario, PHP y MySQL.

6.

Seguridad y sesiones

El archivo includes/auth.php contiene funciones de control de sesión y rol. El sistema
inicia sesión con session_start, valida claves con password_verify y restringe rutas
privadas con requiere_login y requiere_rol.
Listing 2. Control básico de rol
function requiere_rol($roles)
{
requiere_login();
if (!in_array(usuario_rol(), $roles)) {
header("Location: /hidroaforo_web/dashboard.php?error=permiso");
exit;
}
}

Conexión a MySQL

conexion.php centraliza servidor, usuario, clave y base de datos. También define funciones de limpieza y validación numérica.
Listing 3. Conexión mysqli simplificada
$conexion = mysqli_connect($servidor, $usuario, $clave, $base_datos);
if (!$conexion) {
die("Error de conexion a MySQL: " . mysqli_connect_error());
}
mysqli_set_charset($conexion, "utf8mb4");

9.

Consultas públicas

Los archivos consulta_estaciones.php, consulta_campanas.php, consulta_aforos_liquidos.ph
y consulta_aforos_solidos.php usan consultas JOIN para mostrar información relacionada sin requerir login.
Listing 4. Consulta JOIN de estaciones
SELECT e.*, r.nombre_rio, c.nombre_cuenca
FROM estaciones e
INNER JOIN rios r ON e.id_rio = r.id_rio
INNER JOIN cuencas c ON r.id_cuenca = c.id_cuenca
ORDER BY e.codigo_estacion;

10.

Descargas CSV

Los scripts de la carpeta descargar envian cabeceras HTTP de tipo CSV y escriben
filas con fputcsv. Esto convierte datos SQL en archivos descargables.
Listing 5. Cabeceras de descarga CSV
header("Content-Type: text/csv; charset=utf-8");
header("Content-Disposition: attachment; filename=tw_hydrodata_aforos_liquidos.csv");
$salida = fopen("php://output", "w");
fputcsv($salida, ["fecha", "cuenca", "rio", "estacion", "caudal_m3s"]);
